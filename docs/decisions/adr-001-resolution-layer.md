# ADR-001: 换层——分布为主体 + 有限真个体窗口

## 状态

accepted（据 `docs/history.md` 第一章 / 第二章追记）

## 背景

个体引擎每步成本 ∝ 人口，而人口只会增长——原模型在数学上无法长期演化。在单机上对个体引擎做的全部优化都**没有突破 O(人口)**，瓶颈是"每个成年人以固定速率产生事件"，不是驱动器或常数。

## 考虑过的方案

### 方案 A：继续优化个体引擎（被拒）
- 优点：语义不经近似（逐个体是真值）。
- 缺点：离散事件 DES 仅 1.1–1.2×；稀有事件降频只降"单次评估成本"不降"唤醒数"；空间局部化仅 ~5%。**渐近瓶颈不变**。
- **拒绝理由**：问题是 O(人口) 本身，任何常数级优化都救不了长期演化。

### 方案 B：分布为主体 + 有限真个体窗口（采纳）
- 优点：每 tick 成本与 N 无关（O(占用桶数)），单位数可推到千万级；窗口保留 ≤ `capacity` 个真个体，留住"活的世界"。
- 缺点：测度是**近似**，必须靠收敛验证兜底；身份在分辨率切换时**不守恒**（重采样）。

## 选择

方案 B。**个体引擎保留为语义真值参照**（`SIM_MODE=individual`）；测度层一切近似必须**收敛**于它（门槛见 [`AGENTS.md`](../../AGENTS.md)「项目级约束」）。

## 后果

### 正面后果
- 人口 1000×（1k→1M）单步仅 ~2.6×，且随占用桶数饱和；局部化 + 稀疏计数后 1e6 人口 ~1.75ms/step。
- 分层清晰：语义真值（个体）/ 承载（测度）/ 观测（窗口）三件事解耦。

### 负面后果
- 引入近似层，需持续用 `bench.convergence --full-compare` + 收敛门槛守住。
- 分辨率切换**身份不守恒**（`coarsen → materialize` 是重采样新代表）——易被误当"守恒量"。

### 需要跟进的
- 任何流算子改动都要跑守恒审计与收敛对比（见 [`bench/README.md`](../../bench/README.md) 守恒纪律）。
