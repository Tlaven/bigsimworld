# ADR-010: 小计数共演单元的「整数语义」（mini 的婚配/死亡 = 信用发放）

## 状态

accepted（2026-10-18；**修订 2026-10-19**——发放**选人**改为确定性加权均匀，见文末「修订」段。其余条款不变）

## 背景

Stage 25 的分辨率层一致性审计发现既存隐疾：均值场 `marriage` 每 tick 把每个单身桶按分数移走 `to_marry × count / singles`——对 `count = 1.0` 的整人桶就是 **1.0 → 0.999444**；`death` 对 60+ 桶同理（每 tick 按比例削）。而 `ClusterStore.extract` 只从 `count ≥ 1.0` 的桶析出整人 ⇒ **只含单身（或 60+）的共演单元粗化一步后不可物化**；旧代码静默失败、却仍计入"换档"（"幽灵换档"）。观测读数与复现见 [`reviews/2026-10-18-resolution-consistency-audit.md`](../reviews/2026-10-18-resolution-consistency-audit.md) §5。Stage 25 已先做诚实计数（`blocked`、不计换档）；本 ADR 记录行为侧的修复。

理论先例：Scheffer et al. 1995（同记录 §6）——"**小内部量 → 回到离散/随机处理**"（其超个体内部量 < 1 时用 Bernoulli 决定灭绝，而不是继续做分数位移）；且个体引擎（语义真值）的婚配/死亡本来就是**离散事件**，本方案让 mini 在个人尺度上回到与真值同型的离散发放。

## 考虑过的方案

- **方案 A（采纳）= mini 侧「整数语义」信用发放**：`FamilyKind` 的 `marriage` / `death` 换成 `integer_marriage` / `integer_death`——信用累积与全局公式**逐 tick 同源的期望通量**（婚配 `to_marry = min(MARRIAGE_RATE×singles×q×2, singles)`；死亡 `Σ_{≥60} count×DEATH_RATE`）；积满阈值（婚配 2.0 人 / 死亡 1.0 人）即**整人发放**：从 `count ≥ 阈值` 的桶按 **count 降序、平局索引序**（确定性、无 rng）取整 1.0；婚配送入同 `(age,gender,wealth)` 的 `marital=1` 桶，死亡记 `recent_deaths(…, 1.0)`（替换语义，同全局）。全局 `FULL_FLOWS` **一字不动**。

> ⚠️ **「count 降序、平局索引序」已被 2026-10-19 修订推翻**（婚配侧；死亡侧未动）：「索引升序」等价于「年龄升序」（`space.encode` 以 age 为最高位）⇒ 平局主导下系统性**最年轻优先** ⇒ fidelity 台阶。原文保留，修订详文末。更改后的规则 = **确定性加权均匀抽样**。
- **方案 B（拒）提取侧配对补回**：m=0 残量 + m=1 残差拼回 1.0。只治婚姻；**死亡没有"兄弟桶"**（削掉的量已入死亡流，缺额随粗化时长增长）⇒ 治不了死因。
- **方案 C（拒）计数残差账**：提取允许取 <1 桶、差额记新账 species。统一修一切，但要**新增账 species + 改守恒恒等式 + 审计族 + 快照**，并把"整人析出"放宽成"从碎片造人"——大工程、语义倒退。
- **方案 D（拒）整数桶豁免削除**：整人桶不削。小簇婚配/死亡率直接坍缩（削除是唯一驱动）⇒ 等于改率，不可。
- **方案 E（部分采纳）维持现状 + 诚实计数**：Stage 25 已完成（`blocked` 观测面保留）；单独不足以修复。

## 选择

方案 A。要点：

1. **只改 mini（`FamilyKind.flows`）**：全局测度路径零接触 ⇒ 收敛/标定/审计等全部全局读数逐位不变。
2. 信用是**发放器状态、不是质量**：不进守恒恒等式；存 `Measure` 字段（`marriage_credit` / `death_credit`）；`fold_pools` **求和**折叠（mini→mini 合并要带信用）；快照往返（旧档缺字段按 0 兼容）；**回流体区（折入全局测度）时作废清零**——全局没有发放器，信用无意义。
3. 发放选人确定性（**2026-10-19 起：确定性加权均匀抽样**；原「count 降序、平局索引序」已推翻）——不消耗任何随机数，`SIM_SEED` 语义不变。
4. `extract` 的"只取 ≥1.0 桶"规则不动——整数语义的另一半：析出永远是整人。

## 后果

- **正面**：整人桶不再被削（单身 / 60+ 迷你保持可物化）；"幽灵换档"从根上消失（`blocked` 期望 ≈ 0，保留为异常观测面）；mini 在个人尺度上与个体引擎的离散事件语义同型；期望率逐 tick 与全局公式一致。
- **负面 / 边界**：
  - 小簇婚配/死亡的**实现时序**由平滑变整点发放（期望不变、方差变大）⇒ `cluster_fidelity` 等读数会漂移（需复测判读，允许噪声级）；
  - **分数遗留桶**（旧档或出生注入造成的 <1 单身/60+ 桶）不能发放，信用保留不丢——随 dissolve/coarsen 折回自然消解；
  - mini 出生（`birth`）仍是分数注入（不破坏既有整人桶的可物化性）——不在本 ADR 范围。
- **跟进**：若 fidelity 出现系统性恶化 ⇒ 回滚或收窄；遥测→升级触发接线（审计记录 §3 的 #5/#10 缺口）照旧待开。

## 修订（2026-10-19）——发放选人：「最大桶优先」→「确定性加权均匀」

**触发**：本条「跟进」条款第一项的成真。[`reviews/2026-10-19-cluster-gate-triage.md`](../reviews/2026-10-19-cluster-gate-triage.md)：`cluster_fidelity --gate` 自本条落地（`d739304`）起转红——n=400 pop 相对偏差 **~1.8% → ~5.4%**（三个种子块稳健）；消融定位到 **`integer_marriage`**（death/birth 无责）。

**根因**：旧选人 = `(-count, index)` 排序；`space.encode` 以 age 为最高位 ⇒ **索引升序 = 年龄升序**，而 coarsened family 里 `count == 1` 的桶占绝大多数 ⇒ **平局规则主导 = 最年轻单身优先**。实测（同一条 trial / 三臂对照）：coarse(int) 已婚 18–50 的 **≤30 岁份额 0.42 vs 流体 0.24、真值 0.26**（t=1500），已婚 18–50 总量高出 ~25% ⇒ 生育闭合放大 ⇒ 人口超产。

**修订（收窄，非回滚）**：婚配发放选人改为**确定性加权均匀抽样**——位置 = `_mix32(tick, 同 tick 第 k 人) % 整数总权重`，沿**索引升序**按 count 累计定位；期望上与流体版"按桶占比摊派"（≡ 对单身总体均匀抽人）一致（方差仍大于流体，见本 ADR 负面条款）。同桶双取仅当 `count ≥ 2.0`（与旧规则一致；否则会从分数余量桶取走两整人而销毁质量）。**四条性质全部保留**（整人发放 / 期望同源 / 无 rng / 只碰 mini）；**`integer_death` 未动**（消融证明与台阶无关；其排序产生的是"年长优先移除"，不触生育通道——登记为观察项）。

**验收**（全部实测，详见 [`reviews/2026-10-19-integer-marriage-fix.md`](../reviews/2026-10-19-integer-marriage-fix.md)）：消融夹具 pop@400 **1.23%**（改前 5.10%）；`--gate` t=4000 **PASS**（1.23/1.57/0.06%，seed0=101 复现 PASS）；`blocked` 保持 0；全局读数逐字不变（本 ADR 第 1 条约束的护栏）。

**重基线**：cluster 侧读数（cluster_fidelity / resolution_switch 等 mini 相关数字）按新规则重基线；全局路径零接触。
