# ADR-014: 窗口个体的 LLM 可插拔——暂不实现（方向性）

## 状态

accepted（2026-10-18）

## 背景

调研先例（超个体 / EBT / AgentSociety 等）里，"有认知的个体"（LLM 驱动决策）是常见形态。本仓库的窗口承载**语义真值**（个体引擎），于是自然出现的问题：能否把 LLM 接进窗口个体？

- **现状缝**：个体事件机经 `model` **鸭子类型**取基础设施（`characters` / `event_plaza` / `publish_list` / `rng` / `UTC` / `create_character` / `remove_character`）——这是基础设施缝，**不是决策缝**；决策层（婚配 / 生育 / 迁移 / 广场行为）是规则式实现，无外部模型位。
- **方向定位**：这不是缺陷登记，是**范围决策**——LLM 个体与"可聚合、可复现的语义真值"三个既有契约正面冲突（见下）。

## 考虑过的方案

- **方案 A（采纳）暂不实现 + 记录缝与重启条件**：不改代码；登记"LLM 若接，接在**决策层**（事件选择），不是基础设施层"。
- **方案 B（拒）现在加 provider 抽象**（把决策层抽成可注入接口 + dummy 实现）：**落地即死代码**；且"LLM 决策该长什么样"未定义时抽象会**锚错层**（锚在错的粒度上，比不抽象更糟）。
- **方案 C（拒）LLM 个体作为新 kind 的共演单元**（kind 注册表本就支持注入）：混淆窗口的**语义真值角色**——窗口个体是测度层的参照本位（可聚合、可收敛），不可聚合的行为会架空收敛判据的含义（门槛变得不可判读，而不是"变难"）。

## 选择

方案 A。**为什么现在不接（三条契约冲突）**：

1. **确定性**：`SIM_SEED` 契约要求同种子逐位复现；外部 LLM 非确定。兼容形态 = **记录重放**（录制决策流回放）或本地固定种子小模型。
2. **成本模型**：窗口当前成本 ≈ O(capacity × 事件)，近零；LLM 是**逐决策**外部调用，数量级不同——会改变"窗口便宜到可忽略"这一架构前提。
3. **可聚合性（最关键）**：均值场近似要求个体行为有可聚合的统计语义（分布闭合）；LLM 决策无闭式均值场 ⇒ 测度层**无法近似**——"同一批人两种表示"的**守恒**还在（账本不依赖行为），但**收敛门槛失去意义**（没有可比的语义真值分布）。这等于把架构目标（宏观忠实 + 可审计）降级为只审计。

**重启条件（写死）**：三条同时满足才重启评估——① 出现"显要个体的认知 / 叙事"的**产品演示需求**；② 有**确定性兼容宿主**（记录重放 / 本地固定种子模型）；③ 先定义 **LLM 决策 → 事件词汇**的映射，并**明确记账**"收敛门槛如何降级"（例如：LLM 个体只停留在窗口、不参与测度层保真断言）。

## 后果

- **正面**：拒绝在未定义的语义上锚抽象；个体引擎保持可复现、可聚合；不为假想需求扩面（与 ADR-013 同一纪律）。
- **负面 / 边界**：该方向的表达力缺（登记为已知边界）；若需求出现，需要一轮"决策缝设计 + 确定性宿主 + 门槛降级记账"。
- **相邻的合法形态**：若要做"个体叙事"演示，从**只读侧**做（把已有个体轨迹渲染成叙事）——不碰语义真值、成本低、无需本 ADR 重启。
