# ADR-004: 分辨率层保真门槛 = 分层（趋势 + 人口偏差），且**禁止**在生产簇规模上设单点门槛

## 状态

accepted（2026-10-17 拍板；实现在 `bench/cluster_fidelity.py --gate`，CI 慢跑；[`adr-003`](adr-003-interaction-channel.md) 的未定点 4 由本条接管）

## 背景

第三章主张"coarsen 一个家族 ≈ 保留这个家族"，但直到 Stage 16 才有度量（`bench.cluster_fidelity`）。
首测读数 `age_l1 ≈ 0.25` 曾被读成"粗化误差是测度层门槛的 4 倍"——**这个读法是错的**：

- **分箱离散**：生产簇规模 ≤ `max_members=12`，`k=8` 时一个分位数格 = 12.5%（12 人 × 5 年分箱，换 3 个箱就够 0.25）；单 trial 的 `wealth_ks` 能冲到 0.9；
- **相位错位**：resolved 臂每人有独立相位，coarse 臂的 `aging` 锁在 `tick % 360 == 0`；相位对齐后 t=600 时偏差**塌到 0.0000（相位解释 100%）**，t=8000 时只解释 16%（0.2556 → 0.2163）——**连"分解"都随时长变**。

规模扫描（20 trials/t=8000，`bench.diagnose_cluster_bias`，全部 20/20 同号）：

| members | 8 | 25 | 80 | 200 | 400 | 800 | 1600 |
|---|---:|---:|---:|---:|---:|---:|---:|
| `age_l1` | 0.2556 | 0.1514 | 0.0899 | 0.0566 | 0.0454 | 0.0412 | **0.0359** |
| `age_l1 × n` | 2.0 | 3.8 | 7.2 | 11.3 | 18.2 | 33.0 | **57.4** |
| `pop(R−C)` 相对 | — | — | — | −2.3% | **−4.6%** | −1.0% | −0.66% |

两条结论：
1. `age_l1` **仍未平台化**（到 n=1600 还在降），且衰减**远慢于 1/n**（`× n` 一路涨）⇒ 既有离散成分，也有**真实的残留结构偏差**，量级 ~0.03–0.05（与测度层门槛 `age_l1 < 0.06` **同阶**）。
2. **人口偏差不是"随 n 放大"**：它在 **n≈400 见顶（−4.6%）后回落**（n=800 −1.0%、n=1600 −0.66%）。Stage 16 修订里"`pop(R−C)` 随 n 放大、这条比 `age_l1` 更硬"是**两点（200/400）外推**的产物，已按本条更正。

⇒ 需求：**要一个门槛**（否则"粗化变差"无人守），但**任何门槛都不能建立在生产规模的单点读数上**。

## 考虑过的方案

### 方案 A：分层门槛（采纳）
- **结构层**（快，进 `pytest`）：`tests/test_cluster_fidelity.py` 只守结构——工具能跑、字段齐、配对关系成立。**不设阈值**。
- **趋势层**（慢，进 CI 慢跑）：`bench/cluster_fidelity.py --gate` 跑**跨规模 + 配对 + 多 trial**，断言两条：
  1. `age_l1` 对 n **不升**（容差内），且最大 n 处 **≤ 0.06**（与测度层门槛**同阶**，不是等同）；
  2. `pop(R−C)` 的**相对偏差** |mean| / n **≤ 5%**，且**不随 n 增长**（大 n 处 ≤ 小 n 处 + 容差）。
- 优点：把"不可判读的读数"结构性排除在门外；给**唯一**可判读的硬信号（人口偏差，多 trial 20/20 同号）上锁；门槛值与"机制没坏"对齐，而不是与噪声对齐。

### 方案 B：生产簇规模上的单点门槛（被拒）
- **拒绝理由**：正是 Stage 16 说的"把**未决**伪造成**已决**"。该读数被分箱离散 + 相位主导，且**相位贡献随时长从 100% 变 16%** ⇒ 门槛会随分箱粒度 / 时长 / 簇规模漂移，红绿与"粗化好坏"无关。
- 若用"跨 trial 均值"来降噪：均值仍是离散噪声的函数（`members=8` 时 sd 0.087 ≈ 均值的 1/3），门槛无法区分"粗化变差"与"换了一批人"。

### 方案 C：不设数值门槛，只写方法学要求（被拒）
- 优点：绝对诚实，零维护。
- **拒绝理由**：人口偏差这条**可判读**的信号就没人守了；且"方法学要求"不是约束型陈述，无法强制（E3）。

### 方案 D：用分布型指标（KS / gini / 分位）做门槛（被拒）
- **拒绝理由**：生产规模下它们被离散噪声主导（单 trial `wealth_ks` 可达 0.9），不可判读。

## 选择

**方案 A。** 门槛的**形状**比数值更重要：

- **禁止**在生产簇规模（`members ≤ max_members=12`）上设阈值——那里的一切分布型读数都不是"粗化误差的度量"。
- 门槛只在**可判读口径**上定义：跨规模（n ≥ 400）+ 配对试验 + 多 trial（默认 20）+ 固定时长（默认 t=8000）。
  **实现口径（2026-10-19 确权）**：`--gate` 缺省 = t=8000（`GATE_TICKS`）；`--ticks` 显式覆盖；非 gate 模式（A/B 扫描）缺省 t=4000。此前实现误用 4000，CI 长期以 4000 运行（与本文"默认 t=8000"不符，见 [`reviews/2026-10-19-cluster-gate-triage.md`](../reviews/2026-10-19-cluster-gate-triage.md) §4）。
- 门槛是**趋势 + 量级**，不是单次读数：`age_l1` 随 n 不升且最大 n ≤ 0.06；`pop` 相对偏差 ≤ 5% 且不随 n 增长。

## 后果

### 正面后果
- 粗化保真度有了**可执行**的门；"设计必须含跨规模扫描 + 多时长"从口号变成检查器。
- 明确排除"用生产规模单点读数判读该层"这一**已两次踩过的坑**（Stage 7 的 p100、Stage 16 的离散性当信号）。

### 负面后果
- 门槛守的是**机制**（"没坏"），**不保证**生产规模（≤12）的实际保真度——那件事目前**无法度量**，只能声明不可判读。
- CI 多一个**十几分钟级**步骤（t=8000、3 规模 × 20 trials；job 超时 45 min；不是 `pytest` 快跑的一部分）。
- `pop` 的 5% 是**当前观察上界**（n=400 实测 4.6%）而非理论值 ⇒ **余量只有 0.4pp**：换一批种子集时
  该条可能翻红。届时**先按趋势判读**（4.6% → 1.0% → 0.66% 是强信号），必要时**调高上限**——
  调数值不改形状，仍走本条 ADR 的「需要跟进的」。

### 需要跟进的
- **渐近值仍未定**：n 推到 1600 仍在降（0.0359），`age_l1` 的真实渐近值未测到 ⇒ 若将来要**收紧**门槛，先重跑规模扫描。
- **`pop` 系统性多产的机制未定**：候选是"均值场里已婚者的生育闭合"，但**不能用单臂消融**验证（Stage 16 已证明消融只会强行制造新差异），需要新设计。
