# 2026-10-18 · 生产样态注意力轨迹观测（滞回默认拍板的前置）

> 测量轮（**不改行为**）。仪器：`bench/attention_trace.py`。目标：回答"`theta_down`（滞回）该不该默认开"。
> 观察模式：`production` = 与 runner 同构（内生凝视 `endogenous_scale = max(6, capacity/25)` + 显要 0.01）；`none` = 只有衰减（对照）。
> 配置：N=5000 / C=1000 / ticks=2000 / seeds 1、7（production）、seed 1（none）。

## 1. 预注册判据（v3；修订链全记录，每次都朝**更保守**方向）

- **v1**：降档时注意力 ≥ k 的比例 ≥10% 且事件 ≥5 ⇒ 值得启用。
- **v2**（拆分归因）：只看 **`[k, θ)` 带内**的降档（≥θ 的是预算挤压，滞回也不能否决）。
- **v3**（加必要条件）：**上行穿越 θ ≥ 5 次**。理由：带内事件是**平滑衰减的必然产物**——任何从高到低的衰减都会在第一次跌破 θ 时落在带内，它证明不了"振荡"；滞回的价值是抑振荡，没有上行的单向下穿只是把一次性降档**推迟 ~10 tick（纯成本）**。

## 3. 结论

1. **注意力轨迹结构性单向**：内生凝视只对 **resolved** 簇刷新（`_endogenous_attention` 跳过 level 0），降档后**无回升源**；每簇恰好一次下穿（穿越下 84/152/205 = 降档数）、升档 = 0（形成即 resolved，降档后长眠）。**没有振荡可抑**。
2. 滞回的代价是确定的：θ_down=0.45 把一次性降档推迟 ≈ `ln(0.495/0.45)/ln(0.99) ≈ 9–10 tick`（0.40 约 20 tick）——纯成本、零收益。
3. **判据设计教训 #2**（与误差触发研究的"② 单独通过不足"同族）：**判振荡必须看"往返"（上行穿越），不能看"经过"（带内占位）**——后者是平滑衰减的必然产物。后续判据应沿用 v3 的必要条件。
4. **边界**：bench 无观察者 pin、无墙钟负载反馈——live runner 里 `feedback` 的**边际翻转**（预算线附近的簇逐 tick 上下）本仪器测不到；若将来要开滞回，**那才是需要观测的源**（需 live 采样）。本结论只覆盖"衰减 + 内生凝视 + 显要"三路。
5. `production` vs `none`：内生凝视让簇更多（并发 64 顶格 vs 27–32）且降档更晚（驻留中位 131/63 vs 93）——注意力机制在起作用，但不是振荡。
