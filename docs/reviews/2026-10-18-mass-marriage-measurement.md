# 2026-10-18 · 大众婚配「语义双解」测量（窗口单身 × 全局测度）

> 问题：把婚配候选从"coarse 簇"扩到"**全局测度（匿名大众）**"后——(a) 这条通量有多大？(b) 它是"补差"（把 measure 的已婚比例拉向个体引擎参照）还是"加量"（新增通量、可能推过头）？
> **本记录只给数字与读数**；采纳与否由独立决策（ADR）拍板。

## 0. 口径

- **配置**：N=1200、capacity=240、ticks=2000、seeds={1,2,3,4}（与 Stage 20 校准同口径，便于回归）；`--family-pool 0`（生产样态；大众臂的候选不扫簇，该参数对它无意义）。
- **参照** = `EventEngine`（个体引擎，语义真值）；measure 臂 = 全局测度 + 各簇 mini + 窗口角色**合并**统计；口径 = **成年人**（`18 ≤ age < 60`）已婚比例。
- **实验规则** = `bench/probe_rules.py::MassMarriageRule`（**bench 脚手架，非生产路径**）：与 `rules.py::MarriageRule` 的差别只有目标侧——不扫簇、直接产 `scope=("measure",)` 的 `bind` 意图；资格/掷骰顺序/**自有随机流**纪律逐行一致。通道侧**零改动**（N2-8 已提供 R→M 路径）。
- 读数纪律沿用 Stage 20：**null 臂**（`emits_bind=True`、不发意图）隔离 headroom 常驻效应；自有流避免随机流污染；同 seed 配对。

## 4. 双解读数

**扩展读数（新增通量）**
- 通量随 rate **近似线性**（2.5→5.5→12.5→24.5→51.2 crossings 对应 0.05×→1×，无簇臂式的饱和——候选池大得多）；
- 量级可观：1× 时 2000 tick 内约 51 桩跨界婚配（生产样态下簇臂为 **0**）；merged 已婚比例 **+6.4±1.0pp**（Δ vs null）；
- 机制观感：`window_married` 全程 ≤ 8/240 ⇒ 新人配偶多因容量回填被逐出并经折算回测度（marital=1 保留）——**该通量的净效果 ≈ "把大众单身持续转化为已婚"**（净效应低于朴素上界 2×crossings/adults，存在对"本来会发生的窗口内婚配"的替换效应）；
- 配额/headroom 均不构成约束（`cap_per_tick` 从未触顶；headroom 丢弃 ≤4/run）。

**保真读数（能否"补差"）**
- off − ref = **−1.13pp**（复现 Stage 20 的结构性缺口）；
- 但 null − ref = −0.14pp（均值；分 seed 离散 ±3–4.5pp ⇒ SE ≈ 1.6pp）——**这个缺口基本被 headroom 效应（+1.00pp）解释**，不是婚配率亏空，也不是本规则能"修"的；
- 通量从最小档起就是**加法**（Δ vs null 在 0.10× 已转正）；均值意义上"越过 ref"的档位落在 0.05×–0.10× 之间，但那个区间**低于 ref 对比的噪声底**（±1.5pp 级）⇒ **不存在可分辨的"补差"窗口**。

## 5. 结论建议（供拍板）

1. **语义定位 = 扩展**（与 ADR-007 同族："开启 = 新增婚配通量，不属于参照模型的近似"）；"保真修正"的说法不成立——−1.1pp 缺口是 headroom 效应 + 对比噪声，不是婚配通量缺失。
2. 若将来采纳：**默认关**；rate 若定标，可分辨的语义效应从 ~0.25× 起（+1.75pp），1× 已 +6.4pp——远超"补差"所需（≈0），属显著模型改动，必须走正式化轮。
3. `target="both"`（簇 + 大众并存）**未测**：同 tick 双意图会让同一人双婚（通道不在 reserve 时复检发起者婚配态），需要"一人一意图"或合并抽样的守卫——属生产设计。

## 6. 待拍板清单

1. 采纳与否（语义定位建议 = 扩展；默认关）；
2. 若采纳：正式化轮（ADR → N2-7 规格增补 + 危险实现清单 → teach-back → `rules.py` 正式化（target/both 形态）+ runner 开关 → **复跑本测量作为验收**：数字须与本台账一致）；
3. 若不采纳：按铁律 3 记"为什么不"（本对账已备数字）。

## 8. 口径限定

- 单规模单时长（N=1200/C=240/t=2000）；通量与窗口单身数 × ticks 成正比，生产规模（N=5000/C=1000）读数会更大——但"扩展 vs 补差"的定性结论不依赖规模。
- measure 臂是"合并统计"口径；`window_married` 只作机制旁证，不参与判读。
