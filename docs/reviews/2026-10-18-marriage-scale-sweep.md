# 2026-10-18 · 婚配规则跨规模扫描（ADR-009 跟进；`scope=both`）

> 测量轮（**不改行为**）。问题：ADR-009 的"生产速率定标 / 跨规模扫描"待办——规则若开，通量与已婚效应**怎么随规模走**？
> 配置：N ∈ {1200, 2400, 4800}；C = N/5；family_pool = N/7.5；ticks = 2000；seeds 1–3；`--scope both`；rate ∈ {0.5×, 1.0×}；含 `off`（生产口径）与 `null`（占名额不发意图）两臂。

## 1. 读数（3 seeds 均值）

| N（C, pool） | crossings @0.5×（族/众） | crossings @1.0×（族/众） | Δmarried vs null @0.5× | @1.0× | drops/crossings @0.5× → @1.0× |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1200（240, 160） | 11.3（5.7/5.7） | 14.3（5.7/8.7） | +0.0139 | +0.0225 | ~2.7 → ~4.9 |
| 2400（480, 320） | 20.7（10.0/10.7） | 27.0（16.3/10.7） | +0.0200 | +0.0204 | ~3.3 → ~6.0 |
| 4800（960, 640） | 42.0（26.3/15.7） | 52.0（25.0/27.0） | +0.0087 | +0.0119 | ~3.3 → ~5.9 |

**人均通量密度**（crossings / 千人口 / 2000 tick）：@0.5× = 9.4 / 8.6 / 8.75；@1.0× = 11.9 / 11.25 / 10.8。
**headroom 效应**（null − off）：−0.0014 / +0.0022 / +0.0049（噪声级，与 ADR-009 单规模读数一致）。
`off` 基线仍高于个体参照（+0.022 ~ +0.050，已知的测度侧偏高，与规则无关）。

## 2. 结论

1. **通量密度跨规模稳定**（~9–12 / 千人口 / 2000 tick，0.5×–1.0×）——速率是**人均常数**，生产开档可按目标通量线性外推，**不需要按 N 重标**。
2. **已婚比例效应有界、不随规模放大**：Δ vs null ≤ +0.02，且 N=4800 反而最小（+0.009/+0.012）——规则是"轻通量"，不会把宏观推跑。
3. **族侧先饱和**：`drops/crossings` 随 rate 升（0.5× 约 3×；1.0× 约 5–6×），1.0× 时 `dropped:window` 随 N 超线性增长（~150 → ~300）——高 rate 下窗口 headroom 是瓶颈。**若将来开生产，rate ≤ 0.5×** 是稳妥点；在出现消费需求前保持默认关不变。
4. 边界：单时长（2000 tick）、3 seeds、中等规模；生产更大规模下**定性不变**（ADR-009 注），数值会更大。
