# 2026-10-18 · 误差触发研究（审计 #5/#10 的前置：指示器 vs 粗化伤害）

> 背景：一致性审计（[`2026-10-18-resolution-consistency-audit.md`](2026-10-18-resolution-consistency-audit.md) §3）的最后缺口 = **误差侧触发**（Yilmaz #5/#10）。Stage 25 预留的前置 = 相关性研究：先证明指示器有预测力，再谈接线。
> 仪器：`bench.residual_correlation.py`（配对世界：同 seed、同家族；处理臂 resolved 观察 W=720 tick → coarse 演化 T=2000 tick；孪生臂全程 resolved。隔离 = 容量 k + 关闭回填 + 关闭边界维护）。

## 1. 设计

- **指示器**（t = W 读，均为 resolved 可测）：
  1. `flux_z` = `(Σreal − Σexp) / sqrt(Σexp + 0.5)`（telemetry 滚动窗，三类事件合并）；
  2. `phase_disp` = 成员相位的圆离散度 `1 − |mean(e^{iθ})|`（0 = 同相，1 ≈ 均匀）。
- **结局**（t = W+T，处理臂 vs 孪生臂）：`age_l1`（`compare_fingerprint`）、`pop` 相对差、`married_frac` 差。
- **轴**：`k ∈ {6, 8, 10, 12}` × `aligned_phase ∈ {False, True}` × 12 trials/格。`aligned_phase` = 合成"完全同相"轴（相位错位是 Stage 16 记录的主导混淆项），用于检验指示器能否"看见"已知误差。

## 2. 预注册判据（先写死，防事后挑选）

某指示器"可用"须满足其一：

- **① 生产样态内**（`aligned=False` 组）：与 `age_l1` 的 Pearson `|r| ≥ 0.5` 且符号一致率 ≥ 0.8；
- **② 已知轴分离**（跨两组）：指示器与 `age_l1` 在两组间**同向**分离（各 |Cohen's d| ≥ 1 且方向一致）。

## 3. 读数（2026-10-18，12 trials/格）

轴分离（aligned − nonaligned，Cohen's d）：`phase_disp` **−7.14**、`flux_z` −0.07、`age_l1` **−1.51**。

判定：

- **`flux_z`：不可用。** 组内 `r(age_l1) = +0.013`、符号一致 52%、轴分离 d = −0.07——生产簇规模（≤12）下窗内事件计数是个位量级，残差基本是**泊松噪声**。
- **`phase_disp`：仅通过判据 ②（"可用"按预注册口径）。** 轴分离 d = −7.14（与 age_l1 同向）、组内 `r = −0.014`、符号一致 54%——它能"看见"完全同相这一**退化**情形，但**在生产样态内没有判别力**：簇间差异（同 k 内）远小于簇规模带来的常数差（k=6→0.665 … k=12→0.781）。

## 4. 处置

- **按预注册判据**（②通过）实现**缺省关**的接线：`ResolutionManager(risk_alert=None)`——上次观测的相位离散度 ≥ 阈值的 coarse 簇获得注意力地板 θ；缺省 No-Op、快照往返、`telemetry()`/`summary` 增 `risk` 字段。测试覆盖"缺省关不动行为"与"启用时地板生效"。
- **明确不建议默认启用**：判据 ①（生产样态内的判别力）未通过（r ≈ 0）；生产方式下的"同相异常"只在整批同时出生这类边角出现。启用需独立拍板 + 生产标定。
- **`flux_z` 记"为什么不"**：作为调度信号不可用；`telemetry()` 的观测面保留（对账/异常检测仍有用），但**不作触发**。
- **判据设计的教训**：②单独通过不足以支撑启用——下一轮评估指示器时，应把"组内判别力"设为**必要条件**（本轮按预注册执行，不追改判据）。

## 5. 局限

- 孪生臂在 W 之后与处理臂世界本就不同（这正是"处理"）；对照含义 = "若保持 resolved 会怎样"。
- `aligned_phase` 是合成轴（生产不存在完全同相家族）；它只能验证"能看见已知误差"，不能证明生产内可用。
- 网格有限（k ≤ 12、W/T 固定）；`pop_rel` 在两轴同值——与 Stage 16 一致（pop 偏差另有机制，不由相位驱动）。
